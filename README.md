# Periodic Table Project

A visually appealing and color-coded Periodic Table of Elements built using HTML and CSS. The project displays all 118 chemical elements organized according to the standard periodic table layout with different colors representing various element categories.

## Features

* Complete Periodic Table with 118 elements
* Color-coded element categories
* Hover effects for better user interaction
* Attractive gradient heading design
* Organized Lanthanides and Actinides sections
* Clean and responsive layout
* Pure HTML and CSS implementation

## Element Categories

* Alkali Metals
* Alkaline Earth Metals
* Transition Metals
* Basic Metals
* Metalloids
* Nonmetals
* Halogens
* Noble Gases
* Lanthanides
* Actinides

## Technologies Used

* HTML5
* CSS3
